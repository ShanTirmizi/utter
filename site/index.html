How it works

One key tidies. Another rewrites.

Choose sentence by sentence, by which keys you hold. Both can be changed, and dictation can be the fn key on its own.

⌃control ⌥option

Tidy

Keeps your words. Takes out the ums, repeats and false starts, fixes the punctuation, and breaks a long dictation into short paragraphs.

Or just the fn key.

Hold fn to talk, double-tap it to go hands-free. Utter keeps the emoji picker out of the way while it runs, and gives it back when you quit.

Privacy

Your voice stays on your Mac.

Speech is turned into text on your Mac by an open model running on the GPU. Here is everything that ever leaves it.

Audio
Never.
Transcribed on your Mac and then thrown away.
Text
Only if you set it up.
With cleanup by a provider, the transcript goes to that provider with your key. With a local model, nothing leaves at all.
History
Never.
One file on your Mac, readable only by you. Clear it or switch it off.
Your keys
Kept in the Keychain.
Sent only to the provider they belong to, and never shown again once saved.
Anything else
Nothing.
No account, no analytics, no telemetry. Update checks are off unless you turn them on.

Install

Up and running in a minute.

For Macs with Apple silicon on macOS 12 or later.

  1. 1

    Download

    Open the DMG and drag Utter into Applications. It's signed and notarised, so it opens like any other app.

  2. 2

    Allow two things

    The microphone, so it can hear you, and Accessibility, so it can type for you.

  3. 3

    Hold and talk

    The speech model downloads while you go. Then hold the key in any app and say something.

Or use Homebrew

One line installs it, and brew upgrade keeps it current.

Terminal
$ brew install --cask shantirmizi/tap/utter
Or build it yourself

The README lists the tools you need: Rust, Node and pnpm.

Terminal
$ git clone https://github.com/ShanTirmizi/utter.git
$ cd utter && pnpm install
$ pnpm tauri build
